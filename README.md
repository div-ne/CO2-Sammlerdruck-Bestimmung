# CO2 Sammlerdruck Bestimmung

[**Zur Anwendung**](https://co2sammler.streamlit.app/)

## Funktionen

- Berechnung des maximalen absoluten Sammlerstillstandsdrucks
- CSV-Export der Ergebnisdaten

## Eingabeparamter

Folgende Eingaben stehen in der App zur Verfügung:

- Sammlervolumen
- Kältemittelfüllmenge
- Umgebungstemperatur

## Technologie

Die Anwendung basiert auf Streamlit für die Oberfläche, CoolProp für Stoffdaten und thermodynamische Zustandsgrößen und Pandas für Datenaufbereitung.
